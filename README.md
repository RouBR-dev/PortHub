# About

PortHub is an Android application designed to bring game ports from different platforms together in one place.

The project aims to make it easier to discover, organize and access information about games adapted or available for Android, including titles originally released for PC, consoles and other platforms.

---

# Features

- 📱 Android game catalog
- 🎮 Ports from PC, consoles and other platforms
- 📥 Download links
- 🔎 Search and categories
- 📋 Game descriptions and information
- 🖼️ Covers and screenshots
- ⭐ Featured games
- 🔄 New games and content updates
- 🌐 Simple and modern interface
