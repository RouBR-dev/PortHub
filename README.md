</p></div>Sobre

O PortHub é um aplicativo Android criado para reunir e organizar ports de jogos de diferentes plataformas em um único lugar.

O projeto facilita a descoberta de jogos originalmente lançados para PC, consoles e outras plataformas, que possuem versões ou ports disponíveis para Android.

Funcionalidades

- Catálogo de jogos para Android
- Ports de PC, consoles e outras plataformas
- Links de download
- Pesquisa e categorias
- Informações e descrições dos jogos
- Capas e screenshots
- Jogos em destaque
- Atualizações de jogos e conteúdos
- Interface simples e moderna
