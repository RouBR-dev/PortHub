## 📖 Sobre o Projeto

O **PortHub** é um aplicativo Android desenvolvido para reunir, organizar e facilitar a descoberta de jogos portados para dispositivos Android.

Explore jogos originalmente lançados para PC, consoles e outras plataformas, encontre informações sobre cada título e acesse os links de download disponíveis diretamente pelo aplicativo.

Nosso objetivo é oferecer uma experiência simples, organizada e intuitiva para quem gosta de jogar no Android.

## ✨ Funcionalidades

- 🎮 **Catálogo de jogos:** explore diferentes títulos e ports disponíveis para Android.
- 🔍 **Pesquisa:** encontre jogos com mais facilidade.
- 🗂️ **Categorias:** navegue pelos jogos organizados por categorias.
- 📥 **Downloads:** acesse os links de download disponíveis.
- 🖼️ **Capas e screenshots:** visualize imagens dos jogos.
- ⭐ **Destaques:** descubra os jogos selecionados em destaque.
- 📚 **Biblioteca:** organize e consulte seus jogos.
- 🔄 **Atualizações:** acompanhe novos conteúdos e atualizações.
- 📝 **Informações detalhadas:** confira descrições e informações dos jogos.
- 🎨 **Interface moderna:** navegue por uma interface simples e intuitiva.
